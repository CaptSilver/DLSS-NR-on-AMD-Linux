# 0.6.0 — Linux / Proton

Experimental Linux/Proton integration of **DLSS-NR on AMD 0.6.0**, continuing
the port by bulacha3 and guentra. Checked in Oblivion Remastered on RX 9070 XT.

## Changes

**Upstream:** fidelity improvements, fixes for flickering dark areas and small
lights in pre-upscale mode, faster auto-exposure adaptation, and RX 6000/RDNA2
support. The upstream author reports faster RX 9000 inference in Fast mode.
[Original upstream notes](https://github.com/danielblnc/DLSS-NR-on-AMD/releases/tag/v0.6.0).

**Bridge:**
- Forwards `hipHostMalloc` and `hipHostGetDevicePointer`, the two HIP calls 0.6.0
  adds. The bridge table moves to ABI 5; mismatched older components are refused.
- Fixes a black screen when a game re-creates its FSR context right after the
  first job. The mod restarts its frame counter on the same flag buffer, and the
  bridge refused the new frame 1. A finished startup probe now resets that
  buffer's frame slots.
- Fixes a black screen with 0.6.0 when the game supplies an exposure texture.
  Its `k_expo_resolve` kernel runs before `k_import`, and the bridge refused it
  as the first kernel on the work stream.

**Installer:** no longer aborts when the home directory sits behind a symlink,
such as `/home -> /var/home` on Bazzite and other Fedora Atomic / ostree systems.

## Linux performance observations versus 0.5.0

### Oblivion Remastered — 60-second MangoHud captures

| | 0.5.0 | 0.6.0 |
| --- | ---: | ---: |
| Displayed FPS (average) | 102.7 | 99.7 |
| 1% low (displayed) | 48.7 | 47.5 |
| Network time per job | 7.0–8.0 ms | 6.0–8.2 ms |

One capture per version, gameplay portion only, scene not controlled between runs.
Settings: 2226 × 1252 windowed, FSR 3.1.0 with frame generation, DLSS-NR Fast,
pre-upscale (network on the 1485 × 835 render frame), Proton 11.0,
RX 9070 XT / Ryzen 9 9950X3D. Displayed FPS includes generated frames; the game
rendered about half of them. The network is faster in 0.6.0, but it is roughly a
third of each rendered frame, so the difference is within run-to-run variation at
the displayed-FPS level.

## Install or update

Download **`dlssnr-linux-portable.zip`** and its **`.zip.sha256`** file from Assets.
Close the game, extract into a new directory and run **`./install.sh`** as your
normal user, without sudo. You need your own `nvngx_dlssnr.dll` (310.8.0.0) or
converted weights; neither is included. To update an existing install, close the
game and run the installer again; model data and visual settings are kept.

The installer creates **`.dlssnr-linux` beside the selected game executable**.
[Installation guide](../INSTALL.md#where-the-mod-is-installed).

## Coverage and limitations

Startup, gameplay, frame generation and an early FSR context re-creation were
checked in **Oblivion Remastered on RX 9070 XT / gfx1201, with Fast arithmetic**.
The 0.6.0 session logged **4,805 ordered handoffs**; all **28 periodic summaries**
report zero skipped jobs and timeouts. That is one game on one system.

The three-game checks (Cyberpunk 2077, 007 First Light, Atomic Heart) were made
with 0.5.0 and have not been repeated with 0.6.0; see the
[0.5.0 notes](0.5.0.md#coverage-and-limitations). Other GPUs, including the RDNA2
support upstream added, and long-duration stability have not been validated.

The ZIP contains the installer, bridge components, matching sources and licenses.
It does not include NVIDIA model files or weights, the upstream setup, or AMD
runtime libraries.
